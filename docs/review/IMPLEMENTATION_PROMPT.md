## Phase 1 — Close repository safety boundaries

1. **Path safety (F01/F09).** Add validated repository-relative paths and reference names shared by every entry point. Reject absolute/traversing/metadata-targeting tree/index paths and invalid ref names. Guard Windows drive/UNC/backslash/case/ADS/reparse behavior and Unix symlink parents. Use rooted filesystem operations where needed; lexical prefix checks are not enough. Preflight every target before mutations. A malicious tree must not write outside the worktree or into `.git`.
2. **Safe checkout and removal (F02/F03).** Build a worktree operation plan from HEAD/index/worktree/target. Ordinary switch/checkout must refuse overwriting staged, unstaged, or untracked work and preserve compatible local edits. Keep explicitly destructive operations separate. Honor `rm --force` and `--cached`; remove only requested tracked files and only empty leftover directories. Validate all paths before removing any. Propagate I/O failures and define recovery from partial execution.
3. **Real transactions (F04).** Implement an exclusive lock guard, safe cleanup, and atomic/durable publication policy. Acquire locks before reading mutable state/CAS checks, and hold them through commit. Never truncate or remove another process's lock. Implement create-if-absent refs, loose/packed precedence, HEAD/reflog consistency, and platform-correct replacement. Define failure semantics for multi-file state; rename alone is not a multi-file transaction.
4. **Index encoding (F05).** Write valid v2/v3/v4 encoding or perform an explicitly supported semantic-preserving conversion with the correct version header. Preserve required flags and supported extensions; reject unsupported mandatory features without rewriting the index. Bound counts, varints, and path lengths. Git-created v4 indexes must survive `ox add` and every other mutator.
5. **Parser and SSH hardening (F11/F13).** Replace unchecked delta operand indexing with bounded readers and checked arithmetic. Bound inflation, object counts, allocations, and delta depth; detect cycles/self references. Validate SSH destinations before spawning, safely quote remote paths, preserve absolute paths, and correctly honor documented SSH environment settings and executable paths with spaces.

Phase 1 gate: existing-lock sentinel tests, dirty checkout/rm tests, hostile tree/ref/path tests, v4 round-trip tests, parser truncation tests, and SSH recording-helper tests pass. Preflight failures leave HEAD/index/worktree/ref/lock snapshots unchanged. Add error injection around write/sync/rename. Do not claim crash-proof behavior without a demonstrated recovery design.

## Phase 2 — Correct object, index, and history semantics

6. **Repository context and object reads (F08/F16).** Introduce a shared repository context separating worktree, git dir, common dir, format, config, object reader/writer, index, and refs. Use `RepoObjectStore` for repository reads and loose storage only where writing is intended. Resolve indexed REF_DELTA bases with bounds and cycle detection. Support or explicitly reject bare/gitfile/linked-worktree/unsupported-format layouts before mutation. Do not accidentally fall back to a parent repository.
7. **Conflicts and sequencing (F06).** Reject nonzero index stages in write-tree/commit/amend. Represent stages 1/2/3 as base/ours/theirs, never as a conflict-marker blob. Persist merge/replay state, return nonzero on conflicts, preserve correct parents, and implement restartable continue/abort for supported merge/rebase/cherry-pick/revert operations. If an operation cannot yet be made safe, gate it with an explicit unsupported error before any mutation.
8. **Tree merge semantics (F14).** Keep existence, mode/type, OID, and byte content separate. Handle add/delete/type conflicts before text merging. Preserve binary content, CRLF, and final-newline state; never use lossy UTF-8 conversion on data that will be written into Git objects. Treat missing/corrupt object reads as errors, not empty files.
9. **Stash (F07).** Use one implementation for CLI/TUI. Save base/index/worktree state with Git-compatible parents; restore the worktree only after durable stash creation. Apply by merging rather than unconditional checkout. Pop only after successful application; retain stash on conflicts. Correctly drop the selected entry and update the remaining stack/reflog. Preserve staged/unstaged separation and tracked deletions.
10. **Ref operations (F09).** Handle packed-only refs and loose shadows on create/delete/update, validate names at trust boundaries, refuse unmerged branch deletion unless explicitly forced, and maintain reflogs consistently.
11. **Staging/status/commit (F15/F16).** Support deletion staging and subdirectory pathspec scope; do not skip tracked files because of ignore rules. Report mode/type/conflict changes. Add racy-index protection and error-aware status computation. Handle symlinks/modes/gitlinks deliberately. A staged empty tree is valid when deleting the last tracked file; compare trees rather than rejecting an empty index.

Phase 2 gate: a differential matrix compares Git and ox object/tree bytes, parents, refs, index stages, worktree bytes, exit statuses, and resumability. Run it with loose objects, after Git/ox packing, with OFS_DELTA/REF_DELTA, on staged/unstaged/binary/deletion/conflict fixtures. Verify produced repositories with `git fsck --full`, `git verify-pack`, and index inspection where appropriate. Tests must assert expected semantics, not just successful execution.

## Phase 3 — Make transport correct and bounded

12. **Protocol phases (F12).** Separate advertisement, capability negotiation, ACK/NAK, sideband pack streaming, and report-status parsing. SSH discovery must stop at the correct flush rather than await EOF. Never append ACK/NAK text to pack bytes. Reject partial prefixes and incomplete frames. Negotiate only supported advertised capabilities; reject unsupported protocol versions explicitly. Add bounded streaming, timeouts/cancellation, and child cleanup/wait behavior.
13. **Safe send/receive (F10).** Compute the reachable object closure for requested refs and negotiated haves, not `collect_all_objects`. Unreachable objects must never be copied merely because they exist locally. Reject non-fast-forward updates without an explicitly supported force request; enforce CAS and checked-out destination policy for local transport. Validate/quarantine incoming pack data before ref publication. Parse unpack/`ok`/`ng` responses and update tracking refs only after confirmed remote acceptance.
14. **HTTP/SSH integration.** Build loopback HTTP and local Git upload-pack/receive-pack fixtures, plus fake SSH argv/process-lifecycle helpers. Cover advertisements, capabilities, ACK/NAK, chunking, sidebands, errors, timeout, rejection, authentication failure, concurrent remote advancement, and cancellation. Do not use credentials or real remotes for automated tests.

Phase 3 gate: local servers prove complete clone/fetch/push workflows and meaningful failure handling. Push rejection returns nonzero and preserves tracking refs. Divergent local destinations remain unchanged. Reachability tests prove synthetic unreachable private blobs are absent at the destination. No deadlock or unbounded buffering on stalled/malformed responses.
